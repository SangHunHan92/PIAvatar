# Assets

All data required by the demos is in
[`piavatar_assets.tar.gz`](https://drive.google.com/file/d/1lne-a_8KgmWxA3vScRxJiqS4hm5l8sNI/view?usp=sharing)
(≈550 MB) — extract it in the repository root. `3dgrut/` is installed
automatically by `setup_env.sh`, and `output/` is generated by the demo runs.

## Archive contents

| Path | What it is |
|---|---|
| `AnimatableGaussians/datasets/Actor{01,05}/.../part_split_meshes.glb` | OSSO skeleton meshes (bone particles) |
| `AnimatableGaussians/datasets/Actor01/.../actorshq_smpl_params.npz` | body shape for the cloth demo |
| `model/pillow2sofa_whitebg-trained/` | 3DGS pillow reconstruction |
| `model/MeshAsset/{football,rucksack}/*.glb` | object meshes |
| `smpl_models/smplx/`, `smpl_models/mano/` | SMPL-X body models — [smpl-x.is.tue.mpg.de](https://smpl-x.is.tue.mpg.de) |
| `AnimatableGaussians/datasets/pose/AMASS/CMU/` | AMASS CMU pose clips (two are our hand-edited derivatives) — [amass.is.tue.mpg.de](https://amass.is.tue.mpg.de) |
| `AnimatableGaussians/datasets/avatarrex_zzr/` | AvatarReX preprocessed data — [Animatable Gaussians](https://github.com/lizhe00/AnimatableGaussians) |
| `third_party/MPMAvatar/data/body_models/TR00_E096.pt` | VPoser v1.0 checkpoint — [smpl-x.is.tue.mpg.de](https://smpl-x.is.tue.mpg.de) |
| `third_party/MPMAvatar/data/a1_s1/a1_amass_spin.npz` | pose clip synthesized from AMASS |

Third-party data is redistributed for convenience and remains under its
original (research-only) license — see the linked sources.

## `a1_canonical_assets.npz` (loose-garment demo only)

`third_party/MPMAvatar/data/a1_s1/a1_canonical_assets.npz` is derived from
[MPMAvatar](https://github.com/KAISTChangmin/MPMAvatar)'s a1_s1 data
([ActorsHQ](https://actors-hq.com/)-based, no redistribution license), so it is
not included. Obtain MPMAvatar's a1_s1 assets from their repository to run the
loose-garment demo; all other demos run without it.

Maintainers: `scripts/collect_assets.sh` gathers the files from the dev tree,
`scripts/pack_assets.sh` builds the archive.
